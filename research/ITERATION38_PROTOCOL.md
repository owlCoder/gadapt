## Mathematical comparison problem (explicit restricted research formulation, not claiming source SNDlib model identity)

One **static unsplittable directed path per demand pair**, common across all temporal matrices. Bidirectional source links modeled here as **one shared undirected capacity resource** (traffic in both directions sums; deliberate conservative interpretation, not a claim about DFN optical hardware). `P_d` contains first exactly TWO loopless least-hop paths over original 26 links, deterministically enumerated with lexical tie-breaking. Each source link chooses at most one of its **listed source capacity-price options** (or zero capacity at zero incremental cost if never used); this is an **EXPLICIT-one-option decision we impose**, not inference about underlying source modular capability rules. The same plan `y_e` and route choices `z_{d,p}` apply throughout all 288 matrices: no scenario-dependent purchases, no per-scenario routing recourse. Source preinstalled cost/capacity and routing/setup cost included using their source definitions if nonzero (assert and handle; no silently dropping). Demand units are Mbit/s per official readme; source module-capacity units assumed compatible only if original source confirms (if incompatible, stop; report model uncertainty).

For each edge `e` and temporal matrix `t`: `L_et(z) = sum_d q_dt sum_{p contains e} z_dp`. Constraints: `sum_p z_dp=1`; `L_et(z)<=precap_e + sum_k cap_ek*y_ek`; `sum_k y_ek<=1`; `z,y` binary. Minimize total installed source price `sum_e[constant preinstalled_cost_e+fixed setup_e*used_e+sum_k module_cost_ek*y_ek] + source routing_cost*flow`, with explicit linearization if nonzero. Source network is expected to have zero setup/routing costs; if not, preserve mathematically instead of ignoring. If no supported module can satisfy a route, objective infeasible, not capping/fake purchase.

**Exact MILP reference**: `scipy.optimize.milp`/HiGHS on the SAME two paths, option list, chronological TRAIN traffic matrices, with logged solver status, feasible incumbent, lower dual bound, MIP gap, and wall time limit 180 s; never claim optimal when gap/termination does not certify it. **Original GAdapt**: GA on the same binary `z_d in {0,1}` choices; for each trial build link peak across all TRAIN times and select cheapest sufficient listed source module per edge, or reject if insufficient. GAdapt is not granted a different feasible set. No tuning based on solution quality. GA params: population 24, generations 128, cost diversity log_relative, `population_mutation="cost_diversity,parent_diversity"`, 360 actual fully checked objective evaluations maximum per run, 12 preselected seeds **3800..3811**; timeout 240 sec, no misleading `result.success` as proof of network capacity feasibility. Log and count EACH attempted objective evaluation, including rejected, numerical unknown and budget exits; GA source valid incumbent checked independently.

## Endpoints and honest inference

Primary descriptive diagnostic: best verified **TRAIN feasible** common-plan source cost per GA seed versus MILP incumbent and MILP dual bound on exactly same model; relative gap `(GA_cost-MILP_lower_bound)/max(1,abs(MILP_lower_bound))` is a certified *upper bound on GA distance to optimum* only when dual bound valid (and nonnegative objective), not achieved objective improvement vs MILP. Secondary: train and holdout number of violating snapshots, worst capacity excess in source units, per-evaluation progress, true objective count, CPU time. If MILP infeasible/timeout, clearly report. Single MILP run is a deterministic/reference optimization, not n=12 independent matched statistical trials. No hypothesis test about new algorithm superiority: **baseline experiment establishes numerical ground truth and identifies feasibility/optimality gap before any novel method is proposed**.
