**Date:** 2026-10-22 (Serbia local). Written and committed **before any I32 physical AC runs**. Scope: `owlCoder/gadapt:main` only; no upstream edits. This is *not* a blinded, completely untouched topology (earlier I17 has nominal IEEE14 data), but a distinct 14-bus network from I29-I31 IEEE118 and new predeclared 3-scenario robust requirement. **No claim of algorithmic scientific originality** for first-failure screening.

## Frozen question
Does the I31 conclusion (early reject increases robust feasible discoveries under a fixed true physical AC budget, distinct from censored-score effects) transfer to IEEE14? No parameter tuning or posthoc scenario selection from I32 outcomes.

**Original physical system**: `pypower.case14()`: 14 original BUS, 5 online GEN, 20 original BRANCH, generator gencost and 9D decision vector from *unchanged I17 model* `IEEE14EconomicPFFeasibleSubset`: non-slack PG of four generators plus VG of all five (original source P bounds and generator-bus VMIN/VMAX). Source P/Q/V, thermal positive RATE_A at both terminals, complex AC KCL all independently validated. PYPOWER original Newton–Raphson `runpf(PF_ALG=1, PF_DC=0, ENFORCE_Q_LIMS=0, PF_TOL=1e-8, PF_MAX_IT=40)`. No fake free AC. This is a fixed-PV subset of original AC-OPF, **not the full freely dispatched source AC-OPF**; no claim of real network operational applicability.

**New deterministic I32 profiles** on *this IEEE14* case: `nominal` original PD,QD; `odd_bus_plus1pct` original `BUS_I` odd PD/QD multiplied 1.01 and even 0.99; `even_bus_plus1pct` reverse. Changes apply to all bus PD/QD including original zero/negative demands; original PG/VG inputs, other bus/gen/branch/gencost data, source thermal ratings unchanged. No load rebalance beyond solver's actual slack PG response. Scenarios are synthetic; they do **not** represent measured utility contingencies.

**Four GAdapt arms + two SciPy DE arms**:
- `gadapt_full_true`: full 3 physical AC, true mean of original source scenario economic costs plus 1e5 x sum of measured scenario violations.
- `gadapt_full_censored`: full 3 physically paid AC, same first measured source violation censure `1e9+1e5*v` as fixed screening, with original true feasible economic cost only if all three feasible. This is a control, not new algorithm.
- `gadapt_stop_fixed`: original opt-in I29 first-failure screening, scenario order exactly as above.
- `gadapt_stop_adaptive`: original empirical beta(1,1)-smoothed measured failure order, same scoring.
- `de_full_true`: SciPy differential evolution full 3 physical AC. `popsize=5,maxiter=12,tol=0,atol=0,polish=False,seed=<paired>,updating="immediate"`.
- `de_stop_fixed`: identical DE with first-failure screening (no adaptation).
Every method runs in a fresh original case/model with predeclared `random.seed(seed);numpy.random.seed(seed)` setup for the real GA; no cross-arm physical training, cache or shared physical evaluations.

**12 fresh seeds `2104..2115` inclusive**, no post-run seed choice. At most **180 actual native AC per method × seed**, 72 optimizer runs, **12,960 true AC maximum**. GAdapt `population_size=12,cost_diversity_metric="log_relative",population_mutation="cost_diversity,parent_diversity",exit_check="generations",number_of_generations=128,exit_function=lambda:remaining<3,timeout=240`. GA default behavior unchanged. All methods use identical 9D source bounds. At most 2 real AC budget calls not spent by a screening method because a complete three-scenario check is reserved before new candidate. DE may return success=False after consuming budget, which is not the same as physical infeasibility. Numeric non-convergence => `unknown` never `physically_infeasible`. Original source-feasible verdict requires **all three individually physically run and converged**.

## Primary/secondary endpoints and failure handling
- **Primary**: paired 12-seed binary success of *at least one actually all-3 source verified robust feasible* solution. Prespecified comparisons: (a) GA full_true vs GA full_censored (score effect); (b) GA full_censored vs GA stop_fixed (physical screening opportunity with same score); (c) GA stop_fixed vs GA stop_adaptive (scenario ordering); (d) GA stop_fixed vs DE stop_fixed (optimizer baseline) and (e) GA full_true vs DE full_true. Report exact 2x2 paired success table, two-sided exact binomial/McNemar on discordants (even if no discordants). No claim of significance without adequate evidence or multiple comparison correction.
- **Secondary**: number of *truly attempted* AC calls including non-convergent; first true physical AC count to robust incumbent; full-validated candidate counts, early proven screening counts (not independent replicates), truly measured best original source mean gencost **only on all-three feasible**, all failure seeds, number of unobserved skipped scenarios, source KCL and original P/Q/V/RATE_A diagnostics. Report number of requests and elapsed time separately; no unexecuted AC imputation. Economic cost comparable only within same I32 original three-scenario physics, not IEEE118 or I17/IEEE14 nominal separate problem.
- Results are potentially all zero; do not adjust original generator range/scenario stress/budget/seed counts afterwards. If a preflight check fails, **do not** start 12,960 physical solves. Fix implementation only, with audit disclosure before first true I32 AC.
