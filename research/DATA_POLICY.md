# Research data policy and reproducibility

**Current documentation policy — 2026-11-01.** The previous Serbian versions remain in Git history. This document describes the completed physical research-layout migration and the current English-language documentation rules.

1. **Historical migration:** 341 original research-root documents and scripts were moved byte-identically to `research/legacy/flat/`. Their old/new paths and Git blob hashes are recorded in [MIGRATION_MANIFEST](MIGRATION_MANIFEST_2026-11-01.json). Active I64/I65 reports and raw results were not relocated.
2. **Do not rewrite the science:** No revision of frozen protocols, historical results, negative outcomes or experimental archives as part of documentation language cleanup. Preserve the original Serbian source hash and exact archived copy for every translated active report.
3. **Compatibility:** To run historical entrypoints locally, use `python research/compat/restore_legacy_paths.py --apply --verify`. It creates only missing aliases after complete preflight. Historical regression has not been fully demonstrated in the new layout.
4. **Raw results:** All 2,717 original result files remained unchanged during migration, with the same paths and Git SHA values. Small fixtures may be tracked; large outputs must have hashes and stable storage outside ordinary Git history. Never fabricate missing data.
5. **Scientific reproducibility:** Freeze source version, dependency versions, task instances, seeds, all physical call budgets, transformation parameters and independent witness checks before confirmation. Report `NOT_SOLVED`, failures and negative outcomes.
6. **New research:** Code and tests go under `research/iNN/`; active reports and preregistration files remain accessible under `research/ITERATIONNN_*` until safely archived. Do not quietly alter scientific source material.
7. **Operational safety:** Never write to upstream `bpzoran/gadapt`, alter GAdapt defaults during documentation work, rewrite Git history, or launch expensive CI automatically. `[skip ci]` is not a guarantee about every workflow.
8. **Language and provenance:** New documents use English. Historical `_SR` filenames are retained when necessary for backward links, even where the content has been translated to English. The [language audit](LANGUAGE_AUDIT_2026-11-01.json) distinguishes translated documents from unchanged Serbian sources. Translation is not a new benchmark.
